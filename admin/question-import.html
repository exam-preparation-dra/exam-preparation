Gemini API Key সেটআপ

আপনার Google AI Studio থেকে পাওয়া ফ্রি API Key এখানে দিন। এটি শুধুমাত্র আপনার ব্রাউজারের Local Storage-এ সেভ থাকবে, কোথাও আপলোড হবে না।

কীভাবে প্রশ্ন ইম্পোর্ট করবেন?

১. API Key: প্রথমে উপরের "API Key" বাটনে ক্লিক করে আপনার জেমিনি কী সেভ করে নিন।

২. লোকেশন: উইজার্ড খুলে কোন ব্যাচ, বিষয় ও টপিকের প্রশ্ন বানাচ্ছেন তা সিলেক্ট করুন।

৩. ছবি থেকে প্রশ্ন (AI): বইয়ের পাতার ছবি আপলোড করুন এবং কতগুলো প্রশ্ন লাগবে তা লিখে দিন। AI নিজে থেকেই প্রশ্ন, অপশন ও ব্যাখ্যা বানিয়ে দেবে।

৪. টেক্সট পেস্ট: যদি আগে থেকেই ফরম্যাট করা প্রশ্ন থাকে, তবে "টেক্সট পেস্ট" অপশনে গিয়ে পেস্ট করে প্রিভিউ দেখুন।
